## Claude-specific notes

- `src/temperament/scale_list/twelve_tet.rs` is 5.8k lines of scale data. Use Grep for a scale name; never read the whole file.
- Methods generated by `#[duplicate_item]` don't appear as literal `fn name` in the source. Search for the bare name to find the substitution table that produces it.
- After changing anything public, run `cargo test` and `cargo test --features winit`; `tests/public_api.rs` is the check that the crate still works from outside.
